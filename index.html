② 加工链路（L2 → L1/L0 → L3/L4/L5 → L6 → 输出）


        

          
L2 数据治理 · 筛选与质量门

          
输入原始 17 序列 + 行情 kline（含日/周/月频）

          
加工分位/偏离(dev)/3m/12m 变化率 → 时效审计（逐序列 staleness）→ 剔除滞后月度序列的单方向判断权

          
产出干净、带新鲜度标签的特征矩阵 + 数据支撑度

          
瓶颈：月度序列滞后 3–7 天；非公开数据（持仓/席位/逐厂产量）缺失 → 用 zhiji + 五步漏斗补救

        


        

          
L1/L0 特征值加工（零品种逻辑统计 + OOS 验证）

          
输入kline + 特征矩阵

          
加工L1 auto_profile：z分数/趋势/波动/信号（不写死任何铅逻辑）；L0 伦铅→沪铅领先信号做真实 OOS 回测

          
产出行情画像 + 唯一经 OOS 验证的真领先信号（命中0.652/夏普5.05/二项p=0.0138）

          
瓶颈：新品种 ID 采集最耗时、无法自动化；数据 <2年 无法做 OOS；阈值需人工标定

        


        

          
L3/L4/L5 通用模板 prompt + 铅特征卡（裁决）

          
输入L1/L2 特征 + L0 领先 + 新闻分桶

          
加工L3 逐条打分（非抵消，输出每条方向/强度/优先级/证据）；L4 同花顺 4 层优先级硬编码仲裁（P1 已验证现货 > 成本支撑 → P2 变化方向 > 绝对水平 → P3 供应>需求 → P4 时间）+ 时间维度横切；L5 新闻分 6 桶

          
产出方向 + 置信 + 支撑阻力 + 核心矛盾 + 强化/证伪触发 + 裁决理由链

          
瓶颈（优势）：仲裁已硬编码可复现（同花顺为人工主观权重，常不一致）；待补：机构真研报来源（用户拍板）

        


        

          
L6 校准与多版本结构化输出

          
输入L4 裁决 + 全量证据 + 完整分析正文

          
加工置信校准（OOS 指标）；套用同花顺式「5维100分」打分；按投资者类型生成格式化简报

          
产出详尽分析正文（保留）+ 标准晨报/短线/产业/机构/散户 5 类简版研报

          
瓶颈：LLM 解盘需提示词校准；认可度指标仅覆盖 OOS（命中/净收益/夏普/p），待补「决策采纳率 / P&L贡献」

        

      


      

        
③ 对标同花顺（护城河定位）

        

          
维度同花顺问财我们(铅看板)

          
数据覆盖全（SMM/Mysteel/LME/海关/席位）zhiji 观/料/讯 17序列 + 伦铅L0领先

          
机构观点有（研报/电话会）近似（新闻共识），真研报源缺失

          
因果验证无法真实OOS回测能跑真实OOS（唯一真领先）

          
仲裁主观权重+经验（易不一致）硬编码可复现（4层优先级）

          
品种扩展通用但浅品种卡工程化迁移(SOP 2–4h/品种)

          
结构化输出强（4类模板+5维打分）本版新增（5子标签+示意评分）

        

        
结论：同花顺赢在"数据全+机构全+产出实用"；我们赢在"真实OOS因果 + 仲裁可复现 + 品种卡可迁移"。互补——用同花顺产业先验当候选池，用我们OOS当最终筛选器。调研详见 docs/STRUCTURED_OUTPUT_RESEARCH.md

      


      

        
④ 迭代优化空间（参考同花顺建议）

        

          
闭环归因
信号→价格→归因→权重调整，让权重自动优化而非人工主观

          
认可度补全
加「决策采纳率 / P&L贡献」两项，形成 预测力→稳定性→实盘→决策价值 链

          
机构研报源
接入真研报（用户拍板来源），补 L5 机构共识短板

          
非公开数据
若可接入持仓/席位，提升数据支撑度分项
